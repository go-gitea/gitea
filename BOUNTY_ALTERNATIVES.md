# Alternative Bounty Platforms to Bountysource

Since Bountysource is no longer operational, Gitea recommends the following alternatives for funding open-source bounties:

## Recommended Platforms

| Platform | Model | Payout | Community | Status |
|----------|-------|--------|-----------|--------|
| [Algora](https://algora.io) | Issue-based bounties | USD/USDC | Growing | Active 2024-2025 |
| [Polar](https://polar.sh) | Fund open issues | USD/USDC | Growing | Active 2024-2025 |
| [IssueHunt](https://issuehunt.io) | Crowdfunded bounties | USD | Established | Active |
| [Gitcoin](https://gitcoin.co) | Protocol grants + bounties | USD/crypto | Large | Active |
| [Code4rena](https://code4rena.com) | Security audits | USD/crypto | Established | Active |

## Setup for Gitea Projects

1. **Algora**: Add issue labels, link in docs, creators receive direct USDC payouts
2. **Polar**: Embed badges on issues, automatic GitHub sync
3. **IssueHunt**: Submit project, community funds bounties
4. **Gitcoin**: Grant program application, recurring funding
